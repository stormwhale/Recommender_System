# Recommender_System
projects on testing different recommender systems

### Models tested: 
1) PySpark ALS,
2) SVD,
3) content-based,
4) global average estimator
5) LLM Hybrid project utilizes ALS and content-based filtering with Ollama Gemma 3 integration.
6) Deply files are files required to package docker image and upload to Azure container instance.
